# Neumorph Music

เว็บแอปเครื่องเล่นเพลงสไตล์ **neumorphism** เน้นใช้งานบนมือถือ เลือกไฟล์เพลงจากเครื่องมาเล่นบนเว็บได้ทันที
พร้อมอีควอไลเซอร์แอนิเมชันที่ขยับตามระดับเสียง (dB) ของเพลงแบบเรียลไทม์

## วิธีเปิดใช้งาน

**แบบเร็วที่สุด:** ดับเบิลคลิก `index.html` เปิดในเบราว์เซอร์ได้เลย (ไม่ต้อง build)

**แบบติดตั้งเป็นแอปบนมือถือ (PWA / ใช้งานออฟไลน์):** ต้องเปิดผ่าน `http://localhost` หรือ `https://`

```bash
npx serve .
# หรือ
python -m http.server 8080
```

ถ้าจะเปิดจากมือถือ ให้เอาโฟลเดอร์นี้ขึ้นโฮสต์ static ที่เป็น HTTPS (เช่น GitHub Pages, Netlify, Cloudflare Pages)
แล้วกด "เพิ่มไปยังหน้าจอหลัก" (Add to Home Screen)

## ฟีเจอร์

- **เลือกเพลงจากเครื่อง:** ปุ่ม `+` เลือกได้ทีละหลายไฟล์ บนคอมลากไฟล์หรือทั้งโฟลเดอร์มาวางได้ และมีปุ่มเพิ่มทั้งโฟลเดอร์
- **จำคลังเพลงไว้:** ไฟล์ถูกเก็บใน IndexedDB ของเบราว์เซอร์ ปิดแล้วเปิดใหม่เพลงยังอยู่ และไม่มีการอัปโหลดไปที่ใด
- **อ่านแท็กเพลง:** ชื่อเพลง ศิลปิน อัลบั้ม และภาพปก จาก MP3 (ID3), FLAC และ M4A
  รองรับแท็กภาษาไทยแบบเก่า (TIS-620) ที่มักเจอในไฟล์ MP3 ไทย ถ้าไม่มีแท็กจะเดาจากชื่อไฟล์ `ศิลปิน - ชื่อเพลง`
- **หน้ากำลังเล่น:** แป้นหมุนแบบนูน ลากที่วงแหวนเพื่อเลื่อนตำแหน่งเพลง แตะลูกบอลตรงกลางเพื่อเล่นหรือหยุด
  ลูกบอลเต้นตามเสียงเบส และมีเส้นสเปกตรัมรอบวง
- **อีควอไลเซอร์แอนิเมชัน:** วัดจาก FFT ของเพลงจริงทีละ dB มี 3 แบบ คือ แท่ง / สะท้อน / คลื่น (แตะที่แผงเพื่อสลับ)
  มีตัวเลขระดับเสียง (dB) แสดงสด และปรับความไวกับความนุ่มนวลได้ในหน้าตั้งค่า
- **EQ 10 ย่านความถี่ (ของจริง):** ปรับเสียงได้จริงด้วย Web Audio มีพรีเซ็ต และกราฟ frequency response
- **แถบเมนูด้านล่าง:** มินิเพลเยอร์ (ก่อนหน้า / เล่น / ถัดไป / แถบเลื่อนเวลา) และแท็บ กำลังเล่น · คลังเพลง · อีคิว · ตั้งค่า
- สุ่มเพลง เล่นซ้ำ (ทั้งหมด / เพลงเดียว) ชื่นชอบ และค้นหา
- ธีมสว่าง / มืด / อัตโนมัติ มีสีหลักให้เลือก 6 สี
- ควบคุมจากหน้าจอล็อกและหูฟังได้ (Media Session API)
- บนคอม: หน้าตาเหมือนมือถือ จำกัดความกว้างไว้ที่ 400px พร้อมคีย์ลัด
  `Space` เล่น/หยุด · `←` `→` เลื่อน 5 วินาที · `↑` `↓` ระดับเสียง · `P` `N` เพลงก่อนหน้า/ถัดไป
- ครั้งแรกที่เปิดจะมีเพลงตัวอย่าง "Sunny Afternoon" ซึ่งแอปสังเคราะห์ขึ้นเอง ใช้ลองแอนิเมชันได้ทันที

## โครงสร้างไฟล์

```
index.html              โครงหน้าจอ + ไอคอน SVG sprite
css/style.css           ดีไซน์ neumorphism (design tokens, ธีม, layout)
js/db.js                เก็บเพลงใน IndexedDB (fallback เป็นหน่วยความจำ)
js/tags.js              อ่านแท็ก ID3v2 / FLAC / MP4
js/engine.js            Web Audio: <audio> → EQ 10 แบนด์ → Analyser → Volume
js/visualizer.js        แปลง FFT (dB) เป็นแท่ง/คลื่น/วงรัศมี + กราฟ EQ
js/demo.js              สังเคราะห์เพลงตัวอย่างด้วย OfflineAudioContext
js/app.js               UI, คลังเพลง, คิวเล่น, ตั้งค่า, ลูปแอนิเมชัน
sw.js                   Service worker (network-first, ใช้งานออฟไลน์)
manifest.webmanifest    ข้อมูล PWA
icons/                  ไอคอนแอป
```

## ข้อจำกัดที่ควรรู้

- **iPhone/iPad:** เลือกเพลงได้จากแอป "ไฟล์" (Files) เท่านั้น เพลงใน Apple Music ติด DRM ทำให้เปิดจากเว็บไม่ได้
  และ iOS อาจหยุดเสียงเมื่อล็อกจอหรือสลับแอป เพราะเสียงวิ่งผ่าน Web Audio (เพื่อทำ EQ และแอนิเมชัน)
- รูปแบบไฟล์ที่เล่นได้ขึ้นกับเบราว์เซอร์ (MP3, AAC/M4A, WAV เล่นได้แทบทุกที่ ส่วน FLAC และ OGG/Opus ขึ้นกับรุ่น)
- พื้นที่เก็บเพลงขึ้นกับโควต้าของเบราว์เซอร์ แอปจะขอ persistent storage ให้อัตโนมัติ
  (ดูพื้นที่ที่ใช้ได้ในหน้า ตั้งค่า → พื้นที่จัดเก็บ)
